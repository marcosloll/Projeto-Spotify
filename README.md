# Spotify Music Search

Aplicação web que pesquisa músicas pela Spotify Web API e direciona o usuário para ouvir a faixa no Spotify.

[![Abrir projeto](https://img.shields.io/badge/Abrir_projeto-1DB954?style=for-the-badge&logo=spotify&logoColor=white)](https://marcosloll.github.io/Projeto-Spotify/)
[![Código](https://img.shields.io/badge/Ver_código-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/marcosloll/Projeto-Spotify)

## Funcionalidades

- Pesquisa de músicas.
- Consulta de dados pela Spotify Web API.
- Exibição dos resultados encontrados.
- Link direto para abrir a faixa no Spotify.

## Executar localmente

Clone o repositório e abra o arquivo `index.html` com o Live Server. Os recursos de busca dependem de acesso válido à Spotify Web API.
